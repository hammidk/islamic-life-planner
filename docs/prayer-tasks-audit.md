# Аудит: создание в блоке намаза (04.11.2026, до правок)

## Как устроено сейчас

- **Блок намаза** — `components/PrayerRow.tsx`. Рисуется на «Сегодня» (`pages/DayTasks.tsx`, `TodayView`) в каждом окне расписания, в том числе в окне **Тахаджуд** (тот же компонент с `id="tahajjud"`). Отдельной страницы или окна намаза в приложении нет: `PrayerTimeline` на Главной показывает только время, «История» — только число отмеченных намазов.
- **Отметка намаза** — `prayersByDate[YYYY-MM-DD][prayerId]` (`prayersDone`, `togglePrayer`), по датам. С пунктами не связана.
- **Кнопка добавления** — «добавить пункт» внутри `ChecklistEditor` (промпт 3): поле с названием, Enter — следующий пункт. Пункт — лёгкий `ChecklistItem { id, title, done, parentId?, note? }` без даты, времени, сферы и повтора.
- **Хранение пунктов** — `checklists[prayerId]` (ключ `fajr`, `dhuhr`, `asr`, `maghrib`, `isha`, `tahajjud`), **не по дате**.
- **Сбрасываются ли отметки каждый день — нет.** В коде нет сброса по дням: `setChecklists` меняет список только при правке пользователем, а `setChecklists({})` вызывается лишь при выходе из аккаунта. Отмеченный пункт остаётся отмеченным во все следующие дни, и когда его отметили — неизвестно.
- **Подсказки** — `prayerChecklistSuggestions = ['Азкары', 'Дуа', 'Чтение Корана']` (`data/taskValues.ts`), чипы «+ Азкары» над полем добавления, тап создаёт лёгкий пункт.
- **Счётчик на блоке** — «выполнено/всего» по пунктам, включая подпункты.

## Компоненты создания задачи

| Компонент | Где | Как вызывается |
|---|---|---|
| `InlineCreate` (карточка `TaskComposer` вверху списка) | «Сегодня», день, сфера, раздел | `useInlineCreateHost(preset)` регистрирует пресет экрана, «+» в нижней панели → `openQuickAdd()` → `mode: 'inline'`. Карточка одна на экран и стоит вверху страницы |
| `QuickAddSheet` (окно снизу) | Главная, Дневник | `openQuickAdd(preset)` без хоста |
| `FullTaskScreen` («Подробно») | из обеих карточек | `expandDraft()` |

Все три работают с одним черновиком `TaskDraft` (`TaskDraftContext`) и создают дело одной функцией `commit` в `QuickAddContext`. Значения по умолчанию задаются пресетом (`Partial<TaskDraft>`). Enter — `commitAndContinue`: создаёт дело и открывает новую карточку с той же датой, сферой и разделом.

Вызвать карточку с готовыми значениями можно (пресет), но только в одном месте страницы. Для блока намаза нужно уметь показать ту же карточку внутри блока — это добавляется как «место» карточки (`slot`), без второго кода создания.

## Решения

- **п.5.** Задачи с `prayerId` на «Сегодня» показываются только в блоке своего намаза: их нет среди строк окон, в «Удел»/«Прочее» и в расчёте «Свободно». Везде остальном (страница сферы, календарь, экран дня, счётчики) это обычные задачи с подписью намаза в мета-строке.
- **п.7.** Отметки пунктов не сбрасывались, поэтому старые пункты становятся задачами **без повтора**. Отметку «сделано» нельзя отнести к сегодняшнему дню (дата отметки неизвестна), поэтому в `doneDates` она не переносится. Отмеченный пункт становится выполненной задачей (`status: 'done'`), чтобы отметка не пропала.
